# 구축 비용과 제작 난이도 — REP5X vs 뱀부 개조 vs Open5x

2026-09-19. 도구 없이 조사로 답하는 항목(R6). 앞선 R2~R4 는 G-code 로 잴 수 있는
것이었고, 이건 **잴 수 없어서 조사해야 하는 것**이다.

⚠ 아래 비용·시간은 **프로젝트가 스스로 밝힌 값**이거나 **판매 페이지 가격**이다.
  우리가 만들어 보고 확인한 것이 아니다. 뱀부 개조 쪽은 공개된 BOM 이 없어
  **추정**이고, 추정은 전부 그렇게 표시했다.

---

## ⓪ 먼저: 막혀 있던 질문이 풀렸다 — **REP5X 는 헤드 회전식이다**

`rep5x.com` 은 개발 환경에서 차단돼 있었고 공식 문서 요약에도 명시가 없어
"헤드인가 베드인가"를 계속 못 정하고 있었다. GitHub 의 조립 지침 원문에 답이 있다:

> **Step 10**: "**Remove original hotend assembly** from printer" /
> "**Attach carriage mount** to X-carriage using original mounting screws"
>
> **Step 11**: "**Mount C-axis (yaw) stepper motor** to carriage mount" /
> "Route slip ring wires through the C-driven-pulley center hole"
>
> **Step 12**: "Route all wires and **Bowden tube** through B_arm center"
>
> **슬립링이 나르는 것**: "hotend fan, hotend heater, hotend thermistor,
> B-axis endstop"

두 회전축이 전부 **X 캐리지 위**에 얹히고, 슬립링이 **핫엔드 배선**을 나른다.
**베드는 손대지 않는다.** 노즐이 기울고 돌며, 부품은 가만히 있다.

### 이게 뒤집는 것

| 앞서 낸 결론 | 어디에 적용되나 |
|---|---|
| 기계 Y 가 **0 으로 축퇴**, XY 스펙이 시간을 안 사준다 (R2·R3) | **베드 회전식에만.** REP5X 는 헤드가 부품 XY 를 전부 훑는다 |
| 원뿔 레이어가 기계공간에서 **수평면** → 노즐 간섭 불가능 (R4) | **베드 틸트식에만.** REP5X 는 부품이 고정이라 성립 안 한다 |
| 도달 영역·대각선 규칙·베드면 침하 `−d(1−cosθ)` (R4) | **베드 틸트식에만** |
| 요구 각속도 `ω = f/r` 이 축 근처에서 발산 (R2) | **둘 다.** C 축이 압출점 방위각을 따라가는 건 누가 돌든 같다 |
| 배선 감김 75분 (R3) | Open5x 의 **배선** 문제는 REP5X 에 없다(슬립링). ⚠ **정정**: 되감기 자체는 REP5X 도 필요하다 — 펌웨어가 C 를 ±360° 로 묶는다 (`platform_comparison.md` ②-4) |

실측으로 확인한 XY 요구량 차이:

| 모델 | 부품좌표 (REP5X 가 먹는 것) | 기계좌표 (Open5x 가 먹는 것) |
|---|---|---|
| funnel 20° | 26.62 × **26.62** | 11.89 × **0.00** |
| lamp 24° | 15.59 × **15.59** | 16.20 × **0.00** |

→ **"뱀부는 CoreXY 라 빠르다" 가 헤드 회전식에서는 다시 성립한다.** 그 이점을
지우던 것은 베드 회전이었다.

### 그리고 이게 선택지의 모양을 바꾼다

REP5X 는 **제어보드와 펌웨어를 통째로 갈아엎는다** (BTT Octopus + Marlin 2.1.x).
"원본 프린터를 최대한 유지" 라는 원래 방침과 **정반대**다. 그리고 대상 기종이
Ender 3 V3 SE / Ender 5 Pro 다 — **뱀부에 REP5X 를 붙이는 선택지는 없다.**
뱀부는 툴헤드도 펌웨어도 비공개라 이식이 곧 새로 만드는 것이다.

즉 두 방식이 한 기계의 두 옵션이 아니라 **서로 다른 기계 세 대**다.

## ① 비용

### (A) Ender + REP5X — 프로젝트 공식 숫자

> "**Cost**: ~$150 in additional components"

BOM 에 들어 있는 것 (전부 `build-guide/universal-parts/bom-universal.md`):

| 항목 | 수량 | 비고 |
|---|---|---|

| GT2 20T 풀리 / 벨트 6×188·6×158 | 2 / 2 | |
| 608 2RS 베어링 / 61804 박형 베어링 | 2 / 2 | B축 / C축 |
| 마이크로스위치, 광학 센서 | 1 / 1 | B 엔드스톱 / C 호밍 |
| **제어보드 (BTT Octopus V1.1)** | 1 | **6축 이상 드라이버 필수** |
| TMC2208 드라이버 | 6 | X·Y·Z·E·C·B |
| **슬립링 MST-005-12A** | 1 | 12채널 2A, 5mm 중공 |
| M3 볼트·열삽입 인서트 | — | |
| 3D 출력 부품 (PETG) | 6종 | B_arm, 풀리 2, 슬립링 홀더 등 |

참고 시세: BTT Octopus V1.1 **$42**(AliExpress) ~ **$70**(Banggood, 드라이버 8개
포함). 보드가 $150 중 큰 몫이다. 슬립링 가격은 확인 못 했다.

⚠ 기존 프린터 값은 별도다. Ender 3 V3 SE / Ender 5 Pro 를 이미 갖고 있지 않으면
그 값이 더해진다.
⚠ BOM 의 구매 링크는 **제휴 링크**다 ("affiliate links … support the Rep5x
project"). 가격 자체는 일반 소매가로 보이지만 알고 볼 것.

### (B) 뱀부 + ESP32 회전 플레이트 — **공개 BOM 없음, 전부 추정**

| 항목 | 추정 | 근거 |
|---|---|---|
| 뱀부 본체 | A1 mini **$299**(세일 ~$224), P1S **$699**(세일 ~$399), P2S $549 | 판매 페이지 |
| 스테퍼 2 + 드라이버 2 + ESP32 | ~$40 | 일반 시세 **추정** |
| 베어링·벨트·감속기 | ~$40~80 | **추정.** 베드+부품을 드는 쪽이라 REP5X 보다 굵다 |
| 슬립링 또는 배선 여유 | ~$20 | **추정** |
| 틸트 크레이들·회전 플레이트 | ? | **설계부터 해야 한다.** 값이 아니라 시간이 문제 |

→ 부품값만 보면 **비슷하거나 조금 싸다.** 비용에서 갈리지 않는다.

### (C) Prusa i3 + Open5x — 지금 슬라이서가 지원하는 것

Duet 보드(RRF3)를 쓴다. Duet 계열은 BTT 보드보다 비싸다 ⚠(정확한 시세 미확인).
Prusa i3 본체도 Ender 보다 비싸다. **비용 면에서는 셋 중 가장 불리하다.**

## ② 제작 난이도

비용은 비슷하니 **여기서 갈린다.**

| | (A) Ender+REP5X | (B) 뱀부+ESP32 | (C) Prusa+Open5x |
|---|---|---|---|
| **조립 지침** | ✅ 단계별 원문 + 사진 | ❌ **없다** | △ 논문·저장소 |
| **BOM** | ✅ 구매 링크까지 | ❌ **없다** | △ |
| **펌웨어** | ✅ Marlin 설정 제공 | ❌ 직접 작성 | △ RRF 설정 |
| **역기구학** | ✅ 펌웨어가 한다 | ❌ 슬라이서가 | ❌ 슬라이서가 |
| **배선 감김** | ✅ 슬립링 (BOM) | ❌ 직접 해결 | ❌ 되감기로 우회 |
| **기계 설계** | 없음 (출력만) | **전부** | 있음 |
| **공식 소요 시간** | **12~19h** (조립 지침) / ~24h (README) | **?** | ? |

REP5X 가 밝힌 시간 분해:
전자 준비 4~6h → 부품 준비 2~3h → 기계 조립 4~6h → 시험·보정 2~4h.

⚠ 같은 저장소 안에서 총 시간이 **12~19h(조립 지침)와 ~24h(README)로 다르다.**
어느 쪽이든 **하루에 끝나지 않는다** 는 것이 요점이다.

### (A) 의 숨은 난이도 — 기종별 추가 작업

Ender 3 V3 SE 는 그냥 붙지 않는다. 저장소 원문:

- X·Z **엔드스톱을 새로 달아야** 한다 (기존 헤드 장착 X 엔드스톱과 CR Touch 가 못 쓴다)
- **핫엔드를 보덴형으로 교체하거나 개조**해야 한다 (기본 직결식은 보덴 커플링이 없다)
- **화면이 Marlin 과 호환 안 된다** → BTT 화면 / 구형 Ender 화면 / 헤드리스
- 핫엔드 통합 케이블을 **개별 배선으로 분해**해야 한다 (슬립링에 채널별로 넣어야 하니)

Ender 5 Pro 판에는 이 목록이 없다. **기종 선택이 난이도를 크게 바꾼다.**

필요한 기술도 명시돼 있다: "Basic 3D printing / Basic electronics (soldering or
crimping) / **Firmware flashing** (Arduino IDE or PlatformIO) / Mechanical assembly
(heat insert, bearing)". 공구: 3D 프린터, 헥스키 M2.5·M3(C축용 긴 것), 와이어
스트리퍼·압착 또는 인두, **멀티미터**, 컴퓨터.

### (B) 의 난이도는 부품이 아니라 **동기화**다

R2 에서 이미 증명했다: 외부 컨트롤러는 **1ms 이내 동기**가 필요하다
(10ms 면 최대 오차 466µm > 압출폭 450µm). 그리고 **시간 기준 개루프 재생으로는
안 된다** — 6분 출력에서 1ms 는 타이밍 정확도 0.003% 이고, 뱀부의 플래너
(가속도·입력 셰이핑)를 슬라이서가 예측할 수 없다.

이건 부품을 더 사서 푸는 문제가 아니다. **성립 여부가 걸린 문제**이고, 남은
탈출구(E 스텝 펄스를 세는 위치 기준 동기)는 아직 **검증 안 된 추론**이다.

## ③ 슬라이서 쪽에 남은 일 (마감 D-20 에서 이게 진짜 비용이다)

| 플랫폼 | 슬라이서가 내야 할 것 | 지금 |
|---|---|---|
| Open5x | 기계좌표 X/Y/Z/U/V | ✅ `to_open5x` + 검사기 C + 되감기 |
| **REP5X** | **부품좌표 + 공구 방향 B/C** (펌웨어가 IK) | ✅ `to_rep5x` + `rep5x_check.py` (2026-09-19) |
| 뱀부+ESP32 | 두 스트림 + 1ms 동기 | ❌ 없다 |

REP5X 쪽 구현은 **Open5x 보다 쉽다.** 이미 있는 것에서 좌표 변환 단계를 **빼면**
되기 때문이다 — 부품좌표는 `backtransform` 결과 그대로이고, 거기에
`B = θ`(상수), `C = φ(p)`(방위각, 연속 누적) 를 붙이면 끝이다. `to_open5x` 가
하던 Rz·Ry 합성이 필요 없다.

✅ **구현했다 (2026-09-19)** — `conical/rep5x.py`, `--mode rep5x`, `rep5x_check.py`.
축 규약은 펌웨어 설정 파일에서 확정했다: `AXIS4_NAME 'C'`(±360°),
`AXIS5_NAME 'B'`(±135°), RTCP 기본 ON, LB=54.67 / LC=1.6.
⚠ 축 **부호**는 조립에 달렸다(`INVERT_I_DIR`/`INVERT_J_DIR`) — 첫 출력 전
`G0 B10` 을 눈으로 확인할 것.
⚠ **되감기는 REP5X 도 필요하다** — 위 ⓪ 표의 정정 참고.

⚠ 그리고 **R4 를 헤드 회전식으로 다시 해야 한다.** 부품이 고정이므로 원뿔
레이어가 기계공간에서 수평이 되지 않고, **노즐-출력물 간섭이 되살아난다** —
다만 노즐이 원뿔면 법선을 따라가므로 3축보다는 유리할 것으로 보인다(미검증).

## ④ 그래서

**비용으로는 안 갈린다** (셋 다 부품값 $150 안팎 + 본체). **난이도로 갈린다.**

- **(A) Ender + REP5X** — 남이 만들어 둔 길이 있다. 지침·BOM·펌웨어가 다 있고
  역기구학과 배선 감김을 하드웨어/펌웨어가 해결한다. 슬라이서 쪽 구현도 셋 중
  가장 가볍다. ⚠ **원본 유지가 안 된다**(보드·펌웨어 교체) — 원래 방침과 어긋난다
- **(B) 뱀부 + ESP32** — 원본 유지가 되지만 **기계 설계부터 전부 새로**이고,
  1ms 동기라는 **성립 여부가 걸린 문제**가 남아 있다. D-20 에 이걸 여는 건 위험하다
- **(C) Prusa + Open5x** — 슬라이서가 **지금 지원하는 유일한 것**이지만 비용이
  가장 높고, 배선 감김(되감기 75분)과 Z 영점 문제를 우리가 떠안는다

> 판단은 재혁 몫이지만, **마감 D-20 기준으로는 (A) 가 위험이 가장 작다.**
> 슬라이서 쪽 추가 작업이 가장 적고(변환을 빼는 쪽), 하드웨어 쪽은 검증된 지침이
> 있다. 대가는 '원본 프린터 유지' 를 포기하는 것이다.

## ⑤ 아직 확인 못 한 것

- ~~REP5X 개조 Marlin 의 축 문자·부호 규약~~ — **확인함**. ⚠ 부호는 조립 의존
- ~~B_arm 의 기하~~ — **확인함** (LB=54.67mm, LC=1.6mm). 이제 헤드 회전식
  도달 영역·간섭 계산을 할 수 있다 ← **남은 가장 큰 구멍**
- 슬립링 MST-005-12A 시세, Duet 보드 시세
- Ender 5 Pro 판의 기종별 추가 작업 목록 (V3 SE 만 공개돼 있다)
- **표면 품질·치수 정확도** (R5) — 실물 없이는 못 잰다
