## 1. 실험 A — **어느 지표가 실물과 맞나** (최우선)

### 질문

"예측대로 나오나" 가 아니다. **"우리가 고친 지표가 옛 지표보다 실물을 잘
맞히나"** 다. 2026-09-19 에 대표 지표가 오버행 아닌 것(희소 인필 위)을 섞어
세던 결함을 고쳤는데, 그 수정이 옳았는지는 실물만 말할 수 있다.

### 왜 램프인가 — **두 지표가 순위를 반대로 매기는 유일한 케이스**

| 램프 | 옛 지표 (페리미터 미지지) | 고친 지표 (진짜 오버행) |
|---|---|---|
| 균일 24° | 3.01% | **1.01%p** |
| 밴드4 | **1.57%** | 1.13%p |
| **어느 쪽이 낫다고 하나** | **밴드4** | **균일 24°** |

한 번의 출력 쌍으로 판정된다. 다른 모델은 두 지표가 같은 순위를 매겨서
정보가 없다.

### 절차

1. 램프를 **균일 24°** 와 **밴드4** 로 각각 뽑는다 (그 외 설정 전부 동일)
2. 서포트를 **끄고** 뽑는다 — 서포트가 있으면 오버행 품질이 가려진다
3. 아래 측정을 한다

### 측정

| 무엇 | 어떻게 | 왜 |
|---|---|---|
| **아래로 향한 면의 처짐** | 캘리퍼스 또는 사진 위 스케일. 설계 대비 최대 편차 | 두 지표가 다투는 대상이 정확히 이것 |
| **실패한 오버행 면적** | 사진을 찍어 격자로 세거나, 눈으로 등급(0~3) 매기기 | 정량이 어려우면 등급이라도 **사전에 정의**해 두고 할 것 |
| 출력 성공 여부 | | 실패하면 그 자체가 결과다 |

### 판정 기준 (**미리** 적어 둔다 — 보고 나서 정하면 안 된다)

- 균일 24° 가 밴드4 보다 아래면 처짐/실패가 **적으면** → **고친 지표가 맞다**
- 반대면 → **고친 지표가 틀렸거나 물리가 기하 판정을 뒤집는다**. 어느 쪽인지
  다시 설계해야 한다
- 차이가 눈으로 구별 안 되면 → **둘 다 이 모델에서는 의미 없는 차이**라는 결과.
  그것도 결과다 (J 의 k_blend 논쟁이 무의미했다는 뜻이 된다)

## 1-bis. 실험 A 가 **축을 하나 더** 판정한다 — 지지 모델 (2026-09-24 추가)

### 왜 생겼나

검사기의 지지 판정이 **미지지 재료도 지지 후보로 센다**(`check_support` 는 이전에
퇴적된 모든 점을 쓰고 `supported` 로 거르지 않는다). 끊으면
(`require_supported_below=True`) 결과가 크게 달라진다:

* 현재값 = **낙관적 하한** — 처진 비드도 온전히 받친다고 본다
* 연쇄   = **비관적 상한** — 전혀 못 받친다고 본다

17 모델에서 이 차이가 **오버행 중앙 +6.5%p, 밴드 우세 11/17 → 0/17** 이다.
**밴드 우세 주장 전부가 "처진 비드도 위층을 받친다" 는 가정 위에 서 있다.**
계산으로는 더 못 좁힌다 → **실물로만 갈린다.**

### 램프가 여기서도 판정 모델이다 — 단 **층고 0.4mm 에서만**

실제 G-code 로 재 본 결과(진짜 오버행 %p):

| 층고 | | 낙관 | 비관 |
|---|---|---|---|
| 0.3mm | 균일 24° | 0.267 | 4.113 |
| | 밴드2 | **0.000** | **0.000** |
| | → 판정 | 밴드2 승 | 밴드2 승 |
| **0.4mm** | 균일 24° | 1.210 | **7.644** |
| | 밴드2 | **0.767** | 8.528 |
| | → 판정 | **밴드2 승** | **균일 승** |

**0.3mm 에서는 두 모델이 같은 답을 내고, 0.4mm 에서 갈린다.**

### 층고 축을 넓혔다 (2026-09-26, `analyze_layer_height.py`) — **0.3 과 0.4 를 둘 다 뽑는다**

위는 두 점이었다. 0.2~0.5mm 로 넓히고 대조 모델까지 보니 **경계가 실재하고 재현된다**:

| 모델 | 비관 판정 경계 |
|---|---|
| 램프 (=허리 r=2), 6점 | **0.30 ~ 0.35** |
| 허리 r=3, 4점 | **0.30 ~ 0.40** |
| 구, 4점 | 전부 무승부 (밴드2 가 균일로 수렴) |

즉 **층고 ~0.3mm 이하면 비관 모델에서도 밴드가 이기고, 그 위면 진다.**
0.3↔0.4 뒤집힘은 우연이 아니었다. (낙관 판정은 층고에 대체로 둔감하다 — 뒤집힘은
램프 0.2mm 한 점이고 거기서 균일 0.000 vs 밴드2 0.020 으로 사실상 동률이다.)

**그래서 실험 A 를 두 층고로 뽑는다** — 정보량이 훨씬 크다:

| 층고 | 두 지지 모델 | 이 출력이 답하는 것 |
|---|---|---|
| **0.3mm** | **둘 다 밴드2 승** | 밴드2 가 여기서 **실패하면 두 모델이 다 틀렸다** — 지지 판정 자체를 다시 봐야 한다 |
| **0.4mm** | **갈린다** (낙관 밴드2 / 비관 균일) | **어느 지지 모델이 맞나** |

램프는 작아서 두 층고 × 두 전략 = **출력 4개**면 된다. 0.3 만 뽑으면 모델 판정이
안 되고, 0.4 만 뽑으면 '둘 다 틀렸을 경우' 를 못 본다.

⚠ 훑은 범위는 0.2~0.5mm 다. **그 밖은 모른다.**
⚠ 오버행은 층고에 **단조 증가**한다(구: 0.25mm 0.018%p → 0.5mm 1.630%p, 90 배).
  **출력물끼리 비교할 때 층고를 반드시 맞출 것.** 층고가 다른 두 출력의 표면을
  비교하면 전략 차이가 아니라 층고 차이를 보는 것이 된다.

### 판정 기준 (**미리** 적어 둔다)

실험 A 의 두 출력물에서 **블렌드 구간(z ≈ 16.3~18.7mm) 과 그 위**를 본다.

| 관찰 | 뜻 |
|---|---|
| 밴드2 쪽 표면이 균일 24° 보다 **깨끗** | **낙관 모델이 맞다.** 처진 비드가 실제로 위층을 받친다 → 현재 기본값 유지 |
| 밴드2 쪽에서 **층 분리·처짐·구멍**이 균일보다 심함 | **비관 모델이 맞다.** → `require_supported_below=True` 를 기본으로 바꾸고 **밴드 우세 주장을 전면 철회**한다 |
| 둘 다 멀쩡 / 둘 다 실패 | 판정 불가 — 층고를 바꿔 재시도 |

⚠ **철회 조건을 미리 적어 두는 것이 요점이다.** 보고 나서 "이래서 그렇다" 를
만들면 안 된다.

### 뽑아 둔 파일 (기계 프로파일 주입, 2026-09-26 에 0.3mm 짝까지 완료)

**파일명에 층고가 들어 있다.** 섞으면 전략 차이가 아니라 층고 차이를 보게 된다.

```
examples/lamp_expA_uniform24_lh03.gcode   층고 0.3  균일 24°
examples/lamp_expA_band2_lh03.gcode       층고 0.3  밴드2 [30°,0°]
examples/lamp_expA_uniform24_lh04.gcode   층고 0.4  균일 24°
examples/lamp_expA_band2_lh04.gcode       층고 0.4  밴드2 [30°,0°]
```

밴드2 프로필은 **두 층고에서 동일**하다 — `[30°, 0°]`, 블렌드 `z 16.35~18.66`
(폭 2.31mm). 층간격 제약이 비율이라 층고에 무관하기 때문이고, 그래서 이 비교는
**층고 하나만 다른 비교**가 된다.

### 뽑은 파일을 검정했다 (진짜 오버행 %p, 검사기가 G-code 에서 층고 자동 감지)

| 층고 | 전략 | 낙관 | 비관 | 판정 |
|---|---|---|---|---|
| 0.3 | 균일 24° | 0.267 | 4.113 | |
| 0.3 | 밴드2 | **0.000** | **0.000** | **두 모델 다 밴드2 승** |
| 0.4 | 균일 24° | 1.210 | **7.644** | |
| 0.4 | 밴드2 | **0.767** | 8.528 | **갈린다** (낙관 밴드2 / 비관 균일) |

→ 설계대로다. **0.3 은 '둘 다 틀렸나', 0.4 는 '어느 모델이 맞나' 를 판정한다.**

⚠ 비관값 하나가 스윕 예측과 다르다: `band2` 0.4mm 가 **8.528**(실제 파일) vs
**8.837**(`analyze_layer_height.py`). 스윕은 직접 슬라이싱 경로를 쓰고 실제 파일은
CLI 경로(메시 세분화 + 적응 현 분할)를 쓴다. 낙관값은 네 파일 전부 정확히 일치하고
**비관값만 어긋난다** — 연쇄 판정이 작은 차이를 증폭한다는 것과 일관되고, 그 자체가
비관 모델의 취약성을 한 번 더 보여준다. **판정은 양쪽 다 균일 승이라 결론은 같다.**
→ 앞으로 실험 수치는 **실제 출력 파일로 잰 값**을 쓴다(위 표).

재현:
```
python3 conical_slice.py examples/lamp.stl --layer-height 0.4 \
  --machine-profile profiles/machine.example.ini -o examples/lamp_expA_uniform24.gcode
python3 conical_slice.py examples/lamp.stl --auto-bands 2 --layer-height 0.4 \
  --machine-profile profiles/machine.example.ini -o examples/lamp_expA_band2.gcode
```
(같은 입력이면 **바이트 단위로 같다** — md5 확인)

⚠⚠ **기계 프로파일은 아직 템플릿이다.** 온도·호밍·프라임 좌표를 실기 값으로
바꾸기 전에는 넣으면 안 된다. 5축 U/V 호밍 자리는 비어 있다(파일 안 TODO 참조).

⚠ **3축으로 뽑으면 밴드2 가 위험하다**: 노즐 간섭 실측 **6.47% vs 균일 3.51%**
(아랫밴드가 24° 가 아니라 30° 라서). 5축(REP5X)에서는 outward 원뿔이 구조적으로
간섭 불가라 무관하다. HotendProfile 이 추정값이므로 수치는 경향으로만 볼 것.

## 2. 실험 B — 계단 자국: **서포트와의 상충이 실제로 보이나**

### 예측 (`analyze_quality.py`, 2026-09-20)

기하만 보면 서포트를 없애는 각도에서 계단이 심해져야 한다. 램프 기준:

| θ | 남은 서포트 | 계단 정렬 (평면 대비) | 평면보다 나빠진 면적 |
|---|---|---|---|
| 0° (평면) | 8.9% | 1.00 | — |
| 30° | 0.9% | 0.91 | 41% |
| **45°** | **0.0%** | **1.09** | **44%** |
| **60°** | **0.0%** | **1.25** | **70%** |

같은 층고(0.3mm) 기준으로는 `cosθ` 가 전면적에 깔려 이게 **가려진다**
(계단 평균은 오히려 좋아 보인다). 그 이득은 레이어가 더 드는 대가이므로,
**층고를 `t·cosθ` 로 낮춘 평면**과 비교해야 공정하다.

### 절차

램프를 **평면(층고 0.21mm)** 과 **60°(층고 0.3mm)** 로 뽑는다.
`0.3 × cos60° = 0.15`… 이 아니라 **수직 간격을 맞추는 것**이 요점이므로,
평면 층고를 `0.3 × cos60° = 0.15mm` 로 두면 수직 간격이 같아진다.
(레이어 수·출력 시간이 비슷해지는지 `analyze_motion.py` 로 미리 확인할 것)

### 측정

- 옆면을 **비스듬한 조명**으로 사진 — 계단이 가장 잘 보인다
- 가능하면 표면 거칠기 측정. 없으면 **같은 조건에서 찍은 사진 비교**로 충분하다
- ⚠ 비드가 계단을 메우는 효과는 계산에 없다. **예측보다 실물이 좋게 나오는 것이
  정상**이고, 그 차이가 얼마인지가 이 실험의 수확이다

### 판정

- 60° 쪽이 눈에 띄게 거칠면 → **상충이 실재한다.** 각도 선택에 표면 항을
  넣어야 한다 (J 에 항 추가)
- 구별 안 되면 → 비드가 계단을 메운다는 뜻. **기하 예측이 보수적**이라고
  기록하고 각도 선택에서 표면 항을 뺀다

## 3. 실험 C — 치수 정확도

### 예측 (계산된 오차원 셋)

| 오차원 | 크기 | 성질 |
|---|---|---|
| 회전축 각분해능 (REP5X C축 26.666 steps/deg = 0.0375°) | 반경 20mm 에서 **13µm**, 50mm 에서 **33µm** | **반경에 비례** |
| 외부 컨트롤러 동기 지각 (뱀부안) | 1ms 에서 최대 **46µm** | **반경 무관** (`f·Δt`) |
| G-code 각도 소수 3자리 | LB=54.67mm 에서 **0.95µm** | 무시 가능 |

⚠ 백래시·마이크로스텝 선형성·벨트 탄성은 **계산에 없다.** 실물에서 이보다
크게 나오면 그게 정상이고, 그 차이가 기계의 진짜 품질이다.

### 절차

**반경이 다른 동심 링 여러 개**를 한 판에 뽑는다 (예: r = 5, 10, 20, 40mm).
각 링의 **직경을 캘리퍼스로** 잰다.

### 판정

- 오차가 **반경에 비례해 커지면** → 회전축 분해능/백래시가 지배한다.
  `steps_per_deg` 를 올리거나 감속비를 바꾼다
- 오차가 **반경과 무관하게 일정하면** → 다른 원인(열수축·스텝 손실).
  회전축 탓이 아니다
- 이 구별이 이 실험의 전부다. **한 번의 출력으로 원인이 갈린다.**

## 4. 실험 D — 출력 시간 (모델 검증)

`analyze_motion.py` 가 낸 시간은 **펌웨어 플래너의 근사**다. 절대 시간의
정확도를 주장한 적이 없으므로, 여기서는 **비교가 맞는지**만 본다.

- 같은 모델을 각도 2종으로 뽑고 **실제 시간을 잰다**
- 예측한 **비율**과 맞는지 본다 (절대값이 아니라)
- ⚠ REP5X 실측 제원에서 **C축 가속도 500 deg/s² 가 지배적 병목**으로 나왔다:
  `a_seg ≤ rot_acc · r / 57.3` 이라 **축 근처에서 가속도가 굶는다**
  (r=8mm 에서 70 mm/s², XY 는 3000). `M204` 로 올려 가며 시간이 예측대로
  주는지 보면 모델과 기계를 동시에 검증할 수 있다

## 5. 순서와 시간 배분

1. **0번(사전 확인)** — 하루. 건너뛰면 기계가 상한다
2. **실험 A** — 가장 중요. 실패해도 다시 할 시간을 남길 것
3. **실험 C** — 링 하나라 싸다. A 와 같은 판에 얹을 수 있으면 얹는다
4. **실험 B** — A 가 끝난 뒤
5. **실험 D** — 다른 실험을 돌리면서 시간만 재면 된다 (추가 출력 불필요)

⚠ **첫 출력은 작고 싼 모델로.** 5축은 3축보다 사고가 쉽고 사고가 나면 기계가
상한다. 램프를 바로 걸지 말 것.
